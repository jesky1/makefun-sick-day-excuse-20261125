A make.fun entry for [The Funniest Sick-Day Excuse](https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36): one line, under 200 characters, that gets you out of work and gets a laugh.

## The entry

> Sneezed so hard this morning my back filed for divorce — I am spending today in mediation with an ice pack and a heating pad.

125 characters, one line. A sneeze, a back, and a divorce settlement — half believable, all ice pack.

## Run

```sh
node main.ts
```

This writes the excuse to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The program validates the line first: 1–200 characters, a single line, no whitespace-only text, no control characters, at least one letter, at least five words, no links, no leading or trailing whitespace.
